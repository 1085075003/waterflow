二、目录怎么用
UnityProject/：标准 Unity 恢复工程，含 Assets、Packages、ProjectSettings 和 AuxiliaryFiles。
unity/：按 Unity 类型整理的独立资源。PNG、WAV、OBJ 可以直接使用；JSON 保留对象字段与引用。unity/unpacked 保存 Unity 容器内部文件；unity/unconverted 保留无法正常转换的对象原始数据。
LevelData/：1350 份起始布局、1350 份解答数据及 gs0 的可读 JSON，含索引和原始资源 SHA-256。
raw/：APKS 内原始内容。含基础 APK 资源、ARM64 原生库、IL2CPP metadata、原始资源包等，便于继续复核或深入分析。
android_decoded/：AndroidManifest、Android 二进制 XML 与资源表的可读导出。
inventory/：原始文件清单、Unity 对象清单、类型信息、引用与校验报告。
工程结构说明.txt：场景、游戏脚本职责、拼块映射、关卡格式及恢复依据。

四、查看真实关卡几何布局
本次新增了独立 Editor 工具，文件为 Assets/Editor/RecoveredTools/FlowWaterLayoutPreview.cs。该工具不是原游戏源码，不会在导入时自动执行。
打开菜单 Tools > Flow Water > Layout Preview。
Asset ID 输入 gm 文件后缀编号，例如 1 对应 gm1；点击 Create selected asset preview in new additive scene。
也可以把 Assets/RecoveredData/LevelData 下的 JSON 拖入 Or decoded JSON 后生成。
工具会在新建的附加场景中摆放恢复的 Prefab，保留位置、原 pieza 名称及原 fijo 字符串。原有场景不会被覆盖；预览场景需手动保存。若已有场景叠加影响观察，可关闭其他场景，仅保留预览场景。
Use final-layout solution 只适用于 Save 类型的 550 份 so 终态布局；另外 800 份 so 是 Save1 操作步骤，工具会提示改用对应 gm 起始布局。
关卡编号不连续：1–200、251–300、351–800、1001–1250、1651–2050。查找以资源名 gmNNN/soNNN 为准；内部 Save.level 有 699 处与文件名编号不同，不能用它重命名或去重。
预览只恢复基础几何。fijo 的复杂状态、旋转与机关、Col 颜色后缀、水流、交互、胜负判定和关卡流程尚未还原。预览中关闭了游戏脚本和 Animator，不通过 Play 还原原游戏。
原场景的拼块索引 292 存在差异，工具提供切换项：主场景 BloqueChorro2；其他游戏场景 Curva4y。默认使用后者。
